
# Comida Search Django
Está com fome? busque um lugar para se alimentar! Usando o Comida Search Django!

### Funcionalidades
* Permite pesquisar restaurantes na cidade escolhida
* Por enquanto busca apenas estabelecimentos no Brasil
* Exibe uma lista com no máximo 40 estabelecimentos
### 📖 Bibliotecas/Pacotes usados 
* Django-bootstrap5
* Charset-normalizer
* Outras no requirements.txt
### 🌐 API de Geolocalização
* Geoapify : https://www.geoapify.com/





## ❓ FAQ

#### Não aparecem resultados para tipo de estabelecimento que procuro

Tente usar termos mais simples como: Pizza, Churrasco, Japonesa etc.

#### Não achei estabelecimentos na minha cidade

Pode ser que os termos contenham erros de escrita ou a API da Geoapify não tenha cadastrado o estabelecimento.
